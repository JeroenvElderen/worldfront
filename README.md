# Travel Empire

A local-first taxi and travel-management game built with Expo and a native Mapbox game world.

## Setup

1. Copy `.env.example` to `.env` and add a public Mapbox token to `EXPO_PUBLIC_MAPBOX_ACCESS_TOKEN`.
2. Create a Mapbox secret token with `DOWNLOADS:READ` scope and set `MAPBOX_DOWNLOADS_TOKEN` before native prebuilds.
3. Run `pnpm install`, then `pnpm exec expo run:android` (Expo Go is not supported because Mapbox is native).

Android is generated by Expo Prebuild from `app.config.ts`; do not commit generated native folders. The Mapbox config plugin injects the Maven download credential during prebuild. Runtime routes use a local interpolation service and therefore need no Directions API configuration.
